前几天 push 完一个新仓库,我盯着 README 看了一会,然后那个 "so what" 的感觉就涌上来了。

不是写不出来。是写出来了,但不知道这意味着什么。

我用 Claude,我用 Codex,基本上脑子里冒出来一个想法,我能在一两天内做出一个能跑的 prototype。GitHub 上的项目列表也在涨。从产出的维度看,我应该是"高产"的。但每次做完之后,那个"嗯,做完了"之后没有下一句的状态,越来越频繁。

一开始我以为是我做得不够多,或者做得不够深。但后来发现不是。我做了不少,做得也不算浅。问题在别的地方。

问题在于:**我没办法对任何一个项目说"这只有我能做"。**

Claude 能做。Codex 能做。任何一个用上同样工具、有差不多想法的人,都能做出差不多的东西。我做的事情,不是被别人做出来过,就是随时可能被别人做出来,差别只是几个晚上的时间。

这种感觉的形状,我后来才看清:**它不是"能力不够"的虚无,它是"执行被商品化"的虚无。**

在 AI 之前,"做出来"这件事本身是稀缺的。一个人能独立做出一个有点东西的 side project,是一种证明——证明你有耐心、有能力、有时间。所以"我做了 X"这句话有份量,它代表了你在别人不愿意或不能够付出的地方付出了。

现在不是了。Claude 帮你写代码,Codex 帮你搭脚手架,deploy 五分钟,域名两分钟。"做出来"的成本被压到了接近零。当成本接近零,稀缺性就消失;稀缺性消失,"我做了 X"这句话的份量就被掏空了。

所以那个虚无不是空穴来风。它是真实的——我们一直用"产出"度量自己的价值,但产出这个货币,正在快速贬值。

---

但我后来想,这个虚无其实是一个**信号**,而且是一个挺好的信号。

它在告诉你:你正站在价值的旧侧。

工具越强,人就越透明。在执行层我们都一样了——写代码、调 API、串组件,Claude 和 Codex 把所有人拉到差不多的水位线上。所以差距不在那一层了,差距搬家了。它搬到了——选择层、品味层、"为什么是这个"那一层。

举个例子。同样用 Claude 写一个 GitHub 项目,有人写出来一个"做完就吃灰"的小玩具,有人写出来一个能解决自己真实痛点的工具,还有人写出来一个能引起一群人共鸣的、带有他个人视角的东西。代码可能都差不多,执行难度也差不多。但份量完全不一样。

差别在哪?在选题。在"我看到了什么、我在意什么、我想让世界看到什么"。

这一层 AI 帮不了你——因为 AI 没法替你拥有视角。它只能放大你已经有的视角。如果你没有,它就只能把你放大成一个高产的、无差别的工具使用者。

所以虚无的真正含义不是"我做不了太多",而是**"我做了的太多东西,没有'我'在里面"**。

这两句话听上去很像,但完全不一样。前者是产能问题,后者是身份问题。AI 解决前者,但只会放大后者。

---

这个区分一旦看清,要做的事就变了。

之前我以为问题是"我还能做什么"。但这个问题在 AI 时代是个假问题——答案永远是"几乎任何东西",而且这个答案越来越没意义。

真正的问题是:**"我想让世界看到什么?"**

这个问题 AI 不能替我回答。Claude 不知道我在意什么,Codex 不知道我经历过什么,它们能放大我,但放大需要一个原点。原点是我自己——我的视角、我的疑问、我厌烦什么、我被什么打动。

虚无其实是一个邀请。它在邀请你从"做了什么"切换到"为什么是这个",从产出度量切换到视角度量。你之前积累的所有"能做"的能力没有白费,它们只是不再是终点了——它们变成了一个非常便宜的脚手架,支撑你去问那个更核心的问题。

我没有立刻给自己一个答案。但我知道,下一个 GitHub 项目,我想先不写 README,先写一段:**"这个项目想说的是什么,为什么是我说。"** 如果这段写不出来,那个项目可能不值得做。

---

工具越强,人越透明。

这听上去像坏消息,但它其实是把所有人推到一个更诚实的位置上——当能力不再是差异,你只剩下"你是谁"这个差异。

而那,从来都是更值得花时间的问题。
